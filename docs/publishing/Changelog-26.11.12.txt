Bridge Builder 26.11.12

- Added supported Bridges & Ports drawbridge, lift-bridge and pedestrian movable styles, including custom-road combinations.
- Updated movable material and decal handling to preserve native appearance while binding supported visuals to the mechanism's current skeleton.
- Added owner-local generated shader persistence and startup restoration. Bridge Builder must remain installed and enabled.
- Changed preview generation to continuous background work with asynchronous native dispatch; matched preview resolution to the visible viewport while retaining antialiasing.
- Improved request-local preparation reuse, nested visual handling and preview diagnostics; removed verified unused code and resources.
- Updated the seven-image showcase, compatibility notes and contributor documentation. Arbitrary third-party bridge assets are not automatically supported.

Back up saves before deleting or recreating bridges: deletion removes placed instances. Existing bridge geometry is not regenerated by an update.
