# Bridge Builder 26.9.25

- Added a **+ Custom road** shortcut to Road Builder, preserving the current bridge configuration. Road Builder remains optional; a dialog explains the requirement when it is unavailable.
- Hide bridge styles whose required DLC or content mods are unavailable or disabled.
- Updated the displayed mod name to **Bridge Expansion Pack**.
- Removed the right-hand scrollbar from the Manage bridges detail panel; the bridge list remains scrollable.

The author has accepted this version in game. Suggested game version: **1.6.\***.

## 简体中文

- 新增“＋自定义道路”入口，可打开 Road Builder 并保留当前桥梁配置；Road Builder 仍为可选模组，缺少时显示提示。
- 隐藏缺少或未启用所需 DLC、内容模组的桥型。
- 模组显示名称统一为 Bridge Expansion Pack。
- 移除管理桥梁右侧详情区滚动条，保留左侧列表滚动。

本版本已通过作者游戏内验收。
