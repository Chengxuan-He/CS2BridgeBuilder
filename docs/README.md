# Project documentation

## Documentation standards

Read [Documentation standards](documentation-standards.md) before creating, editing or relocating documentation. It defines each document type's responsibility and the preservation and navigation rules for this library.

## Constitution

[Project constitution](constitution.md) contains stable governance and principles. Responsibility-based organization does not alter requirement strength or existing specialist exceptions.

## Contracts

[Contracts](contracts/README.md) define obligations, boundaries, ownership, interfaces and lifecycle guarantees. [Complete reading scopes](contracts/reading-map.md) preserve the original mandatory-reading coverage.

## Specifications

[Specifications](specs/README.md) define required behavior, algorithms, formats and acceptance details. They are normative, not optional implementation suggestions. Read each topic with its governing contract. The [LOD specification](specs/lod-spec.md) is mandatory for bridge generation and uses the existing generation contract.
