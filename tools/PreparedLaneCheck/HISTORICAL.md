# Historical native126 fixture

This executable retains the old native126 recipe as historical regression evidence.
It does not validate current production material conversion. The source is local to
this diagnostic and is not compiled into the mod. Its historical success criteria
include restricted recipe mappings that must not be reused as arbitrary-material
support. Use `../MaterialRoutingCheck/MaterialConversion129Check.Editor.cs` for the
current geometry-qualified production entry and native Surface persistence checks.
